# Sol Max 2027 开发实验

这些代码未接入 `examples/gpt61_sol_max_2027`，也未发布到策略库。当前策略检查点为 `fe7100d3a78e3262`。

- `front_outpost.py` 是追加到该检查点生成源码后的实验层；`objective_relay.py` 再追加到其后。二者组合在已见过的八场源码版开发对照中为 7 胜 1 负，不能作为独立泛化成绩。
- `rune_control.py` 是供相同策略命名空间使用的机关射击实验；`rune_probe.py` 在普通物理对局中移动机器人并测试机关，不注入世界状态。它保持每 100 ms 决策，利用云台转动让两发中的第一发安全偏离，第二发命中，并为整对机关目标预留热量。
- 机关实验只有种子 211 的中立场景验证：源码版双方均完成十次命中，获得 60 秒的 1.5 倍攻击和 2 倍冷却；旧安装版双方获得 2 倍攻击和 3 倍冷却。尚未验证其对真实对手的收益。

在仓库根目录运行 `.venv/bin/python experiments/sol_max_2027/rune_probe.py`，标准输出为 JSON。可用 `RMUC_EVAL_RUNTIME` 和 `RMUC_SIM_BINARY` 指定另一份完整运行时；默认使用当前源码运行时。该脚本不会安装或发布策略。
