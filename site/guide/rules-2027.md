# RMUC 2027 规则图解

这一页先解释“为什么这样打”，再列出观战和写策略时要注意的条件。它介绍的是 **Arena-1 中基于 2027 V1.0.0 的实现**；完整数值、接口与适配边界见页末资料。

不认识兵种时，可以先读[从零认识 Arena-1](./what-is-arena)。这里只需要记住：每方有重型、两台步兵、一套空中机器人系统和一台哨兵，共五个出战位置。

## 1. 先找到场上的几个目标

![2027 场地全景：基地在两端，前哨站位于中央高地两侧](/media/rmuc2027-field.jpg)

*实际场地包含高低差、墙体与遮挡。下面的俯视图只标学习所需的地点，不能直接当作可行驶路线。*

[![2027 场地主要地点的俯视示意，标出基地、堡垒、前哨、中央高地、补给和装配位置](/media/field-2027-guide.svg)](/media/field-2027-guide.svg)

| 地点 | 它是什么 | 与你有什么关系 |
| --- | --- | --- |
| 基地 | 每方的核心建筑，初始 10000 血 | 被击毁会提前结束比赛；有无敌条件和装甲开启条件 |
| 前哨站 | 初始 1000 血的建筑，带旋转中层装甲 | 影响前哨控制点；被毁后可能以 500 血重建并改变归属 |
| 中央高地 | 场地中央的抬高台面，两端有坡道 | 高地卡与前哨卡共同组成前哨控制点；台面上还有装配设施 |
| 堡垒 | 基地前方的一块战术区域 | 与基地控制点、防守增益和基地大装甲开启有关 |
| 补给区与资源岛 | 己方后方的补给、取件区域 | 回血、兑换弹药、重型取件；对方禁止进入 |
| 工作台 | 己方补给区域附近的安装地点 | 重型解锁发射机构后，还需要回来装炮 |
| 能量机关 | 中央龙门上的旋转射击目标 | 步兵或哨兵通过击打亮起目标争取团队增益 |

“前哨站”是可被攻击的建筑，“前哨控制点”是控制状态，两者有关联，但不是同一件东西。

## 2. 四个控制点，为什么不等于四个圈？

每方有两个控制点：**前哨控制点**和**基地控制点**。一个控制点由两处增益卡关联而成；满足条件的机器人激活其中任意一处，就可以参与这个控制点的争夺。

| 控制点 | 关联的两处卡片 |
| --- | --- |
| 红方前哨控制点 | 红方前哨卡 + 红方中央高地卡 |
| 蓝方前哨控制点 | 蓝方前哨卡 + 蓝方中央高地卡 |
| 红方基地控制点 | 红方基地卡 + 红方堡垒卡 |
| 蓝方基地控制点 | 蓝方基地卡 + 蓝方堡垒卡 |

[![控制点结构与得分条件：同时控制双方前哨每秒加一，同时控制双方基地每秒加三](/media/control-2027.svg)](/media/control-2027.svg)

*两种控制状态都可参与控制度累计。图中的占卡过程必须满足卡片激活条件；敌方堡垒还有时间与前哨控制条件。*

### 一个从蓝方完全控制开始的例子

假设红方想夺取蓝方前哨控制点：

1. 红方机器人激活蓝方前哨卡或蓝方中央高地卡，蓝方没有机器人激活这个控制点的关联卡片。
2. 持续 **5 秒**，变成红方**临时控制**。这一步不直接变成红方完全控制。
3. 红方临时控制时，如果红方连续 **5 秒**没有机器人激活关联卡片，会转回蓝方完全控制。争夺原有完全控制时，双方同时激活关联卡片会暂停夺取进度。
4. 若前哨站此时被击毁，控制状态还会变化：完全控制变为同方临时控制，临时控制变为同方完全控制。
5. 前哨站已毁且控制点转为完全控制时，前哨站会为相应控制方以 **500 血**重建。

因此，站上卡、持续驻守、拆毁前哨、撤离卡片会产生不同结果。不能把“占到 5 秒”理解为永久占领；基地控制点更只能由原所属方完全控制。

计时依据卡片的有效激活状态。离开卡片后通常还有 2 秒保留时间，所以从画面上驶离到控制状态变化，未必刚好相隔 5 秒。

### 控制度怎样增加？

- 一队同时控制红、蓝两个**前哨控制点**时，控制度 **每秒 +1**。
- 一队同时控制红、蓝两个**基地控制点**时，控制度 **每秒 +3**。
- 完全控制与临时控制都计入；只控制自己一侧的点，不会因此持续加分。

例如，红方保有自己的前哨控制点，又夺得蓝方前哨控制点，并同时保持两者 20 秒，就能在这段时间累计 20 点控制度。控制度只增不减，失去条件后停止增长，不会倒扣已经获得的数值。

## 3. 想打基地，先分清两个条件

**第一层是基地无敌。** 蓝方完全控制蓝方自己的前哨控制点时，蓝方基地不受伤害。红方需要先让蓝方失去这一完全控制状态，例如夺取该控制点，或通过击毁前哨改变状态。

**第二层是装甲是否暴露。** 基地有上层装甲和大装甲。大装甲需要通过敌方堡垒流程开启；上层装甲的可命中不等于能绕过基地无敌。

在 **180 秒之后**，控制着蓝方前哨控制点的红方可以激活蓝方堡垒卡，累计停留 **10 秒**开启蓝方基地大装甲；离开超过 3 秒会清空这段开启计时。进攻者在敌方堡垒承受额外易伤，需要队友掩护。

一个可理解的进攻思路是：**保住己方点 → 争夺敌方前哨控制点 → 维持控制度增长 → 根据时机进堡垒、打基地。** 这是一种战术选择，不是每局必须按顺序完成的任务链。

## 4. 重型：从搬运到火力

![重型机械臂在中央高地的装配台对准科技核心](/media/rmuc2027-heavy.jpg)

*机械臂需要实际取件、搬运并对准核心，发一个“装配”动作不会自动完成整套流程。*

重型开局没有发射机构。它先从资源岛搬运**能量单元**到己方装配区；每队全局有 6 枚，单台最多同时携带 2 枚。装配等级依次解锁：

| 科技等级 | 最早可开始 | 首次完成的主要收益 |
| --- | --- | --- |
| 1 级 | 0 秒 | 重型升到 5 级，增加持续科技收入 |
| 2 级 | 60 秒 | 重型升到 7 级，步兵等级上限提高到 7 |
| 3 级 | 120 秒 | 重型升到 10 级，步兵上限提高到 10，全队防御 25%，解锁发射机构 |
| 4 级 | 180 秒 | 全队防御提高到 50%，进一步增加收入 |

必须先完成前一级。更高等级要求插入、抬升、翻转、旋转与确认；4 级需要两个核心配合，不能仅靠到点等待。

发射机构也可以按时间规则解锁：`300 − M/50 − 2N/3` 秒，其中 M、N 表示本局曾出现的基地血量落后与控制度落后幅度。**解锁之后还要在己方工作台安装模块化 42mm，首发用于确认安装、不造成伤害。**

所以，看到重型暂时没有火力，先检查装配、解锁和安装进度，再判断它是不是策略出错。

## 5. 空中机器人与哨兵

### 空中机器人：撞建筑，不能当空中机枪

![空中机器人接近前哨站中层装甲](/media/rmuc2027-drones.jpg)

*2027 的空中攻击依赖实际飞行与碰撞。前哨装甲会旋转，冲向建筑中心未必命中可计伤的部位。*

一套系统由机库和 2–4 架空中机器人组成，每方最多一套。飞行器受电池、推力、倾角、阻力和高度限制，靠撞击前哨中层装甲或基地装甲造成伤害，基础撞击伤害为 200。

它们没有普通地面机器人的血量机制，但仍有护罩、磨损、被击落和维护相关状态，不是无限使用的火力。**2027 的机库与空中机器人不向策略提供侦察视野**；观察敌方位置仍依赖己方地面机器人。

### 哨兵：姿态是战术选择

7 号哨兵可切换进攻、防御和移动姿态。它适合参与火力、守点与转移，但具体行动取决于策略，并不会因为叫“哨兵”就自动守家。弹药配给、强化预算与姿态衰减也需要管理。

## 6. 用一条时间线看比赛

| 时间 | 新人值得留意的变化 |
| --- | --- |
| 0–60 秒 | 步兵展开抢点，空中机器人开始攻击前哨，重型取件并尝试 1 级装配 |
| 60 / 120 秒起 | 2 / 3 级科技允许开始，是否完成取决于实际操作 |
| 180 秒起 | 4 级科技允许开始，大能量机关进入可用阶段；满足条件的队伍可以进攻敌方堡垒；前哨装甲停止旋转 |
| 中后段 | 装炮重型加入火力，双方权衡补给、复活、占点与基地进攻 |
| 420 秒 | 没有提前结束时，依次比较控制度、攻击伤害、存活地面机器人血量 |

这张表展示规则时机与常见行为，**不是内置策略的表现承诺**。例如 120 秒允许开始 3 级装配，并不代表机器人会在 120 秒完成它。

## 7. 看到这些现象时怎样判断？

| 现象 | 先检查 |
| --- | --- |
| 伤害领先却输了 | 控制度是否落后；2027 到时先比控制度 |
| 前哨打掉后基地仍不掉血 | 对方是否又取得己方前哨控制点的完全控制；命中装甲是否暴露 |
| 前哨又出现了，颜色还变了 | 是否触发控制状态变化与 500 血重建 |
| 步兵到了高地但控制进度不动 | 是否在有效卡片范围、是否虚弱、双方是否同时激活，或中央高地卡是否被互斥占据 |
| 重型很久没有开炮 | 是否完成解锁、工作台安装和首发确认，是否还有弹药与热量余量 |
| 空中机器人“知道”的敌人很少 | 它们不提供视野；不要把观战者看到的全场当作策略的观察 |
