# 训练、对战与回放

## 训练

训练支持全队统筹、单机专精、六机协同和自由适配。全队模式在创建任务前选择机器人型号，
任务生成所选阵容的接口、规则和硬件说明。创建任务后开始开发计时，截止前最后一次有效提交进入策略库。

工作区中有 `AGENT_TASK.md`、中英文参赛手册、`sdk.py`、`arena.py` 和对应策略文件。
将任务文件交给策略开发者或 Agent。使用工作区里的练习客户端测试和提交，不修改受保护的参考文件。

## 对战

RM 对战固定每方六台，编号 1、2、3、4、6、7，双方使用相同硬件阵容，正式比赛 420 秒。
自由对战支持可重复的型号与策略、自定义数量，以及全队统筹与单机控制的混合对战。
阵容可命名保存为卡组，策略库记录策略归属与展示信息。

机器人模型库、硬件数据、上传策略向导、自定义 GLB 外观均由同一后端提供，桌面版全部保留。
自定义外观不改变底层硬件参数和物理规则。

## 观战

观战包括赛前自检与倒计时、镜头控制、双方血量和经济、能量机关、机构进度、击毁播报、
赛后面板与 MVP。音频可独立控制；摄像机、暂停、倍速、全屏和录像保持原有行为。
桌面下载会显示系统文件保存对话框。

## 回放

比赛列表可加载、导出和删除回放，也可导入本地文件。当前 v4 回放共享静态场景数据，
减少重复存储。导入回放属于播放；数值重演校验还要求相同版本的规则与仿真构建。
历史版本的资产和 v2 引擎保留在桌面运行包中，用于兼容旧回放。

使用 CLI 校验回放：

```sh
uv run python -m rmuc_arena verify-replay path/to/match.json
```
