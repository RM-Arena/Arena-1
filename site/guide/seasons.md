# 2027 与 2026：两个赛季怎么选

**第一次使用，先选默认的 RMUC 2027。** 如果要研究旧阵容、对照已有 2026 策略或观看历史比赛，再切换到 RMUC 2026。两者都能使用训练、策略库、RM 对战、自由对战与回放。

这里介绍的是 **Arena-1 对两个赛季的实现**：均以仓库固定的 V1.0.0 手册为依据，并有仿真适配，不代表真实赛事当前全部规定。

## 主要差别

| 项目 | RMUC 2027（默认） | RMUC 2026 |
| --- | --- | --- |
| RM 对战规模 | 5v5 | 6v6 |
| 位置 | 1、3、4、6、7 | 1、2、3、4、6、7 |
| 1 号 | 重型：搬运、科技与后期 42mm 火力 | 英雄：42mm 火力 |
| 2 号 | 无此位置 | 工程：搬运、装配与救援 |
| 3、4 号 | 步兵 | 步兵 |
| 6 号 | 机库 + 2–4 架全自动空中机器人，撞击建筑 | 搭载 17mm 发射机构的空中机器人 |
| 7 号 | 全自动哨兵，有进攻、防御、移动姿态 | 在本项目中改为普通步兵 |
| 到时判定第一项 | 控制度 | 基地剩余血量 |
| 基地保护 | 己方完全控制己方前哨控制点时无敌 | 己方前哨站存活时无敌 |
| 基地 / 初始前哨血量 | 10000 / 1000 | 5000 / 1500 |
| 科技装配执行者 | 重型 | 工程 |
| 典型地形 | 中央高地、制高点台阶、机库、公路起伏、隧道 | 中央高地、资源区、公路与飞坡 |
| 多机协同交付 | 5 份独立机器人策略 | 6 份独立机器人策略 |

## 从 2026 转过来，先改哪几个观念？

### 1. 伤害数字不再是唯一关注点

2027 时间到先比较控制度。保持己方控制点、夺取敌方控制点，可能比继续追击一个残血目标更有价值。只有同时控制两方同类控制点时才持续加控制度，并非站在任意一个圈内就会得分。

### 2. 不再分别安排英雄与工程

2027 的 1 号重型承担搬运、装配与后期火力。开局没有发射机构；完成 3 级装配，或满足基于比赛时间与落后程度的解锁条件后，还要回己方工作台安装模块化 42mm。

### 3. 空中机器人换了一种打法

2026 的空中机器人以 17mm 支援，2027 的空中机器人系统以撞击建筑装甲作战。不能把旧的空中射击策略原样用于机库。2027 每方最多部署一套空中机器人系统。

### 4. 地形与硬件一起选

2027 的制高点有台阶，隧道有净高限制。能上台阶、能折叠过隧道和能沿平地横移是不同能力；同为步兵，也不能假设每个型号走得了同一条路。

## 在哪里切换？

**观看比赛：** 进入 RM 对战或自由对战，在左侧“比赛地图”选择 `RMUC 2027` 或 `RMUC 2026`。切换后检查阵容与策略是否属于对应赛季，再开始对战。

**创建策略：** 在训练页顶部选择规则赛季，再选择开发模式与阵容，最后创建任务。任务目录会生成该赛季的规则、接口和硬件资料。已创建的任务不会因为你切换界面而自动换季。

**查看历史：** 回放保留比赛时的场景和记录。切换当前地图不会把旧回放转换为新规则。

## 型号与策略能混用吗？

| 对象 | 如何判断 |
| --- | --- |
| 硬件型号 | 必须通过目标赛季的制作规范检查。部分步兵跨季合规，英雄、工程与机库等不能随意跨季 |
| 策略提交 | 提交清单包含赛季规则标识，不能因为 Python 文件能运行就当成另一赛季策略 |
| 自定义 GLB 外观 | 替换外观，不改变原型号参数，也不绕过合规检查 |
| 自由对战卡组 | 型号可以重复，但所有卡都必须属于同一比赛赛季，且遵守机库数量限制 |

例如，2731、2732 步兵型号同时符合两个赛季的要求；**为 2027 提交的策略卡仍属于 2027**。迁移代码时应为目标赛季重新创建任务、阅读规则、练习并提交。

## 到时到底怎么比？

两个赛季均为 420 秒，基地被击毁可提前结束；以下顺序仅用于时间耗尽时，前一项相同才比较下一项。

- **2027：** 控制度 → 全队攻击伤害 → 存活地面机器人剩余血量之和 → 平局。
- **2026：** 基地剩余血量 → 前哨是否从未被毁 → 双方前哨均从未被毁时比较前哨血量 → 全队攻击伤害 → 存活地面机器人剩余血量之和 → 平局。双方前哨都曾被毁时，跳过前哨血量比较。

2026 前哨“曾被毁”是永久记录，重建不会抹去。2027 则还要区分前哨建筑与控制点归属，见[2027 规则图解](./rules-2027)。
