# 常见问题

## 必须使用浏览器吗？

不需要。桌面版包含独立窗口和本地运行环境。需要浏览器开发时仍可使用原来的 Web 入口。

## 画质会降低吗？

桌面版使用相同前端构建与素材，不降低模型、阴影或像素比配置。不同显卡、驱动和
系统缩放可能造成细节与帧率差异，不能承诺所有硬件显示结果完全相同。

## 需要 Docker 吗？

内置示例和可信策略的本地体验无需 Docker。执行不可信策略时使用 Docker 隔离模式，
Docker 及其镜像需要单独准备。应用不会把隔离失败的策略自动转成本地运行。

## Python 策略开发还需要安装 Python 吗？

应用运行自身策略时使用内置解释器。外部编辑器或 Agent 调用工作区练习客户端时，
可以使用开发者自己的 Python 3，也可以指定应用包中的解释器路径。

## 可以商用吗？

不可以。当前许可仅限非商业学习和教学活动。公开源码、免费下载安装或修改源码
都不会自动获得商用授权。商业用途需另行取得书面授权。

## 更新后旧回放还能打开吗？

桌面包保留历史资产和 v2 引擎；播放与数值重演不同。重演要求匹配记录时的引擎指纹和规则，
因此无法保证任意旧版本的回放都能用当前引擎通过数值校验。

## Ubuntu 上出现 chrome-sandbox 错误怎么办？

优先安装 DEB 包，而不是直接运行解压后的应用目录。DEB 安装器会配置 Electron 的
沙箱辅助程序及适用的 AppArmor 规则。部分发行版限制 AppImage 的用户命名空间，
请使用对应的系统安装包，不需要全局关闭 AppArmor 或使用 `--no-sandbox`。
