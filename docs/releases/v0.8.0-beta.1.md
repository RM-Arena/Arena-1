# Arena-1 v0.8.0-beta.1

本版本仍为 **Beta**，支持 RMUC 2027 与 RMUC 2026。

## 主要变化

- 新增并行 CLI：批量对局、指定种子、换边、断点续跑、可选回放与 JSONL 结果。
- 新增 `ArenaEnv` / `VectorArena` 和 `env` JSONL 接口，支持持续 reset/step、自博弈、已保存策略对手及回放导出。
- 完善驾驶 HUD、自动瞄准、复活面板、装配交互、赛后高光与音频；同赛季的双方可使用各自锁定的合规阵容。
- 补齐装配失败与单元回收、核心受阻告警、物流衰减等 2027 机制，优化观测传输、实时调度、弹丸计算与渲染。
- 修复重装搬运被救援任务反复打断，以及 Sol Max 串联腿在坡沿驱动轮无载荷时卡住的问题。
- 精简 README，保留展示图与视频入口。

## 策略分发

`examples/` 仅保留 **GPT-6.1-Sol-Max 三叉戟**作为内置参赛策略，默认 2027 对局使用它进行自博弈。其他策略及 PR #4 的策略更新已迁入 [Arena-Strategies](https://github.com/RM-Arena/Arena-Strategies)，可在客户端策略库获取；2026 策略也通过策略库提供。

新增或更新策略请提交到策略仓库，不再提交到本项目的 `examples/`。新工作区使用最小 SDK 模板，单机自博弈在未下载策略时仍可使用空白队友。历史评测记录保留原版本与运行时信息，当前修复版不沿用旧版胜率结论。

## CLI 与训练入口

```sh
# 批量运行可信策略
uv run --locked python -m rmuc_arena run --games 8 --workers 2 --trusted-local --output replays/demo

# 持久的并行训练环境
uv run --locked python -m rmuc_arena env --num-envs 4 --compact
```

策略比赛继续使用默认 **200 ms** 决策预算；CLI 不修改本机 Elo。
