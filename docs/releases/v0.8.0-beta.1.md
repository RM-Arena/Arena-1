# Arena-1 v0.8.0-beta.1

本版本仍为 **Beta**。

## 并行 CLI

- 新增 `run` 多进程调度器，`batch`、`headless`、`match` 共用运行参数。支持 `--workers/-j`、显式种子、换边、共同阵容、战场配置、自由卡组和混合任务 JSON。
- 比赛结果按完成顺序输出 JSONL；任务 ID 保持调度顺序。运行目录记录任务、策略快照版本、引擎/规则/SDK/运行器指纹、结果和汇总，支持 `--resume` 跳过成功任务并重试未完成或失败的任务。
- 默认批量运行不保留逐帧状态和动作历史。可选择保存全部回放或仅保留异常回放；单局 `.json` 输出保留原来的单行结果用法。
- 支持单局墙钟超时、失败后继续执行/快速停止，以及正常退出时的子进程回收。策略决策默认仍为 200 ms；CPU 争用导致超时时可降低并发后续跑。

```sh
uv run --locked python -m rmuc_arena run --games 32 --workers 4 --seed 100 --trusted-local --output replays/train-001
uv run --locked python -m rmuc_arena run --games 32 --workers 2 --seed 100 --trusted-local --output replays/train-001 --resume
```

## 强化学习接口

- 新增 `ArenaEnv` 和多进程 `VectorArena` Python API；每个环境有独立 Rust 仿真和策略状态。
- `env --num-envs N` 通过 stdin/stdout JSONL 提供持续 reset/step、部分重置和回放导出，无需浏览器或 HTTP 服务。
- 支持双方外部控制的自博弈，或指定已保存的策略对手。reset 复用正常的 Rust 进程，并重置对手的私有状态；仿真进程异常后可在 reset 时恢复。
- 返回局部观测、零和奖励、终局/训练截断标记和事件信息；可选攻击伤害奖励塑形、压缩静态字段与供中心化训练使用的完整状态。
- 保留终局观测，由训练器显式重置；示例 `examples/rl_rollout.py` 展示完整的向量采样循环。

```sh
uv run --locked python -m rmuc_arena env --num-envs 4 --compact
uv run --locked python examples/rl_rollout.py --envs 4 --steps 200 --duration 10
```

## 查询和开发工具

新增策略列表/详情/同步、合法型号查询、战场参数与范围导出、提交校验、回放信息与校验、`doctor` 运行时诊断。继续支持策略工作区创建、开发计时、SDK 刷新、提交和组队。

CLI 不修改本机 Elo。标准对局的共同阵容和赛季匹配、自由对战的型号合规、动作归属和队内通信边界继续生效。外部学习器的推理时间不属于策略比赛的计时预算。
