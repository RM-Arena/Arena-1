# Arena-1 v0.7.2-beta.3

本版本仍为 **Beta**，在 v0.7.2-beta.2 的基础上重整录像，并修复几处观战体验问题。

- **录像更清楚**：开赛前勾选「自动录制整场 MP4」，从赛前阵容录到 MVP 结算，保存到「比赛与回放」；对战中随时点「录制片段」，停止后自动转成 MP4 下载。不再需要选择视频格式。
- **保存进度可见**：窗口右下角的录像面板显示录制计时，以及「上传录像 → 转码 MP4 → 保存」各步的百分比与剩余时间。保存失败时可重试、下载原始 WebM 或丢弃。
- **赛后不再「卡住」**：录制整场时，MVP 结算后的「回到战场」「返回数据面板」立即可用；录像在后台保存，期间可以继续操作或切换页面，只是不要关闭窗口。
- **阴影不再延迟**：阴影随每个渲染帧刷新，机器人移动时影子始终在脚下。
- **配乐不再冲突**：播放 MP4 时暂停主页 / 大厅配乐与场内音效。
- **回到对战页是空场**：从其他页面回到 RM 对战时，已结束的比赛不再停在最后一帧，战场回到所选地图的空场，等待下一场开始。
- **策略库**：默认按 Elo 从高到低排列；每份策略显示上传者的 GitHub 主页，内置与在线策略由 RM-Arena 发布，上传时可填写自己的 GitHub 用户名。

已安装 v0.7.2-beta.2 的桌面版会自动提示本次更新。用户策略、比赛与回放数据保存在安装目录之外。
