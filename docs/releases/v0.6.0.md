# Arena-1 v0.6.0

本版将策略更新从安装包中独立出来，并加入可直接分享的 MP4 视频导出。

## 策略自动更新

- 从独立的 [Arena-Strategies 仓库](https://github.com/RM-Arena/Arena-Strategies) 获取策略，首批提供 160 份策略。
- 启动后后台检查，运行期间每 15 分钟检查一次，也可在策略库点击「检查更新」。
- 下载后校验大小、SHA256、归档路径、源码、提交版本、规则版本与展示文件，通过后才切换到新快照。
- 断网或更新失败时继续使用缓存与内置策略；保留用户上传的策略，正在进行的比赛继续使用原版本。
- 训练模式的默认对手也可使用更新后的策略。日后只更新策略，无需重新下载安装包或创建应用 Release。

## MP4 视频导出

- 对战页默认选择「MP4（推荐）」；点击「录制 MP4」，结束时点击「停止并导出」。实时比赛和数据回放均可录制。
- 输出 1920 × 1080 / 30 FPS 视频，使用 H.264 视频与 AAC 音频，包含比分、倒计时、结果叠层和声音。
- 转码在本机完成，安装包自带转码组件；保留 WebM 直接导出选项。
- 转码失败时保留原始录像，可点击「保存原始 WebM」下载。补齐渲染停顿时的视频时长，保持音视频时长一致。
- 单次 MP4 导出的原始录像上限为 1 GiB，时长上限为 1 小时。

## 其他更新

- 包含 v0.5.0 之后加入的 GPT、Gemini、DeepSeek 与 Step5 策略及评测记录。
- 修复 Windows 策略生成过程的换行一致性问题，更新多模型署名校验。
- macOS 安装包使用 ad-hoc 签名，并在发布前检查完整性；此签名不等于 Apple 公证。

## 安装包

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| macOS | Apple Silicon arm64 / Intel x64 | DMG / ZIP |
| Windows | x64 | EXE / ZIP |
| Linux | x64 | AppImage / DEB |

安装包包含 Python 运行环境、Rust 引擎、前端资源与视频转码组件，附各平台 SHA-256 校验文件。
旧安装包需要升级到本版一次，之后策略可以独立更新；引擎、界面与 SDK 更新仍需要新版应用。
用户数据保存在安装目录之外，升级后继续使用本机策略、比赛记录和回放。
