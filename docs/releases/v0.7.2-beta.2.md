# Arena-1 v0.7.2-beta.2

本版本仍为 **Beta**，在 v0.7.2-beta.1 的基础上加入桌面 App 更新检测。

- **自动检查**：桌面版启动 5 秒后检查新版本，运行期间每 6 小时再次检查。发现新版本时弹出提示，同一版本在一次运行中只自动提示一次。
- **手动检查**：「帮助 → 检查更新」随时检查；没有新版本时显示当前版本，网络错误时提供重试说明和下载页入口。
- **下载升级**：按 Windows、macOS 或 Linux，以及 x64 / arm64 架构选择安装包；也可查看版本说明或稍后处理。下载后退出 Arena-1 并安装。
- **Beta 版本支持**：检查包含 GitHub 预发布版本，正确比较 `beta.2`、`beta.10` 等版本号。
- **断网可用**：后台检查失败不弹错误、不阻塞启动或比赛。策略库仍按原有流程独立更新。

旧安装包还没有 App 更新检测，需要先从本发布页手动下载并安装本版本一次。此后可收到新版本提示。用户策略、比赛与回放数据保存在安装目录之外。
