# Arena-1 v0.7.1-beta.1

本版本仍为 **Beta**。

- 2027 规则澄清：重装机器人获得发射机构使用权前，即可在补给区工作台安装模块化 42mm 发射机构。装好后状态为 `fitted_locked`，发射机构不上电、不能发射，对方屏蔽 42mm 弹丸伤害；获得使用权后才可发射。
- 观战新增第一人称视角：点击视窗左侧的悬浮按钮，按红蓝方选择机器人进入其第一视角，镜头随云台转动，可随时退回自由视角。
- 保存的 MP4 录像在比分栏显示双方控制度，赛后数据面板新增累计控制度；2027 超时胜负说明改为按控制度、攻击伤害、剩余血量依次判定。
- 提高 2027 战场还原度：按手册第四章尺寸图与俯视图重新校准白线和红蓝标线，边线变细，补全堡垒四周与台阶前的白线；修正堡垒朝向与条纹、前哨站后方折线台阶、梯形高地 23° 斜面，公路坡道与起伏路段在俯视中对齐；高地按图 4-17 重建；地面与混凝土改用程序纹理并烘焙环境光遮蔽，灯光亮度对照手册渲染图。
- 首页/大厅、赛后数据面板和 MVP 页面换用三首新的原创配乐：混合管弦主题、钢琴固定音型和号角主题，均无缝循环。

2027 规则配置已更新，引擎指纹随之变化；此前保存的回放仍可观看，逐帧重算需要其原始引擎与配置。第三方许可证保持原文。
