# Arena-1 v0.5.0

本版加入默认的 **RMUC 2027 5v5**，同时保留 **RMUC 2026 6v6**。比赛、训练、策略展示与文档均支持两个赛季。

## RMUC 2027

- 新增重型机器人、两台步兵、机库与全自动空中机器人系统、全自动哨兵组成的五位置阵容。
- 实现控制点、控制度、基地保护与前哨重建；新增科技装配、重型发射机构解锁与安装、空中撞击、哨兵姿态等机制。
- 新增中央高地、制高点、机库、公路与隧道等场地内容，按所选赛季检查型号合规性。
- RM 对战、自由对战、开发任务和参赛手册按赛季生成与校验，保留 2026 内容和历史回放支持。
- 修正重型机器人机械臂与模块化发射机构的模型穿插。

## 策略与观战

- 2027 的 58 份内置策略统一署名 **Claude Opus 5.5**。
- 比赛选择器、赛前介绍、计分板、机器人徽标、策略库、历史记录与排行榜统一使用展示名称和开发者信息，兼容旧回放的展示字段。
- 更新 2027 比赛截图与演示录像，修正录像导出的队伍名称、赛季与阵容数量。

## 图文文档与交流

- 新增面向零基础读者的比赛入门、术语表、2027 规则图解和两个赛季的对照说明。
- 补齐首次对战、策略开发、练习提交和回放复盘步骤，并加入五张可放大的示意图。
- 文档主页与 README 增加微信交流群入口；当前二维码有效期至 **2026 年 10 月 22 日**。
- [阅读项目文档](https://rm-arena.github.io/Arena-1/) · [2027 规则图解](https://rm-arena.github.io/Arena-1/guide/rules-2027)

## 桌面与跨平台修复

- 应用、Python 包、服务接口和界面版本统一为 `0.5.0`。
- 桌面启动自检按所选赛季验证机器人数量，支持 2027 的十台和 2026 的十二台。
- 生成的策略源文件与 JSON 固定使用 LF 换行，避免 Windows 与仓库文件的字节校验不一致。
- 异步练习测试为整批策略初始化、运行与清理保留等待时间，继续检查任务结束与策略错误；比赛决策时限保持不变。

## 安装包

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| macOS | Apple Silicon arm64 / Intel x64 | DMG / ZIP |
| Windows | x64 | EXE / ZIP |
| Linux | x64 | AppImage / DEB |

安装包包含 Python 运行环境、Rust 引擎和前端资源，日常运行无需安装开发工具。下载列表附各平台 SHA-256 校验文件。安装包为未签名开发构建，使用许可沿用仓库的非商业学习与教学许可。
