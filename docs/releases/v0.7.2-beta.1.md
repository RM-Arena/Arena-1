# Arena-1 v0.7.2-beta.1

本版本仍为 **Beta**。v0.7.1-beta.1 已打标签但未发布，其内容一并包含在本版本中。

- 第一视角驾驶：实时比赛按 **P** 打开驾驶面板，LINK START 接管一台地面机器人，其余机器人仍由策略控制，比赛记录、回放与 Elo 不受影响。鼠标云台、WASD 底盘、开火与自动瞄准、登阶、小陀螺、超级电容、买弹与补给、取矿与装配均可手动操作；阵亡后锁定镜头并可复活。镜头新增第一视角（4）与环绕（5），各镜头之间平滑过渡。
- 赛前直接在战场上选边、选机体，也可选择本局观战；倒计时开始后不可跳过。
- 赛后流程改为数据面板 → 对局高光 → MVP，每步可跳过。高光从本场回放中自动剪出最多 6 段（结构伤害、输出峰值、多杀、击毁前哨站、能量机关与装配等），以广播式画面播放。
- 音乐：各提示位（赛前、局内开场、赛后数据、MVP、高光）的主题曲随项目发布，同时提供 AAC 与 MP3；局内开场曲放完后接循环曲。首页与大厅换用新的原创配乐。可在本机放置 `<提示位>-custom.m4a` / `.mp3` 替换任一提示位，不进入版本控制。
- 引擎与规则：轮足型号可登上台阶（`climb`）；小陀螺目标角速度与爆发；超级电容 40% 变换损耗；吊射弹道解算；买弹被拒时给出原因；完全控制的前哨站可回血；命中与结构伤害记录攻击者；默认散布与刹车力度调整。
- 2027 规则澄清：重装机器人获得发射机构使用权前即可在工作台安装模块化 42mm 发射机构；装好后为 `fitted`，但在完成 3 级装配或到达 300 − M/50 − 2N/3 秒之前不能开火，对方因此继续屏蔽 42mm 伤害。
- 提高 2027 战场还原度：按手册第四章重新校准白线与红蓝标线，修正堡垒朝向与条纹、前哨站后方折线台阶、梯形高地 23° 斜面与公路坡道；制高点按图 4-17 重建；地面与混凝土改用程序纹理、环境光遮蔽与新灯光。
- 保存的 MP4 录像显示双方控制度，赛后数据面板新增累计控制度；2027 超时胜负说明按控制度、攻击伤害、剩余血量依次判定。
- 性能：静态信息每场只发送一次，快照流量约减为四分之一；机器人与场馆合批绘制，自适应分辨率与阴影刷新，驾驶视角帧率显著提高。
- 启动前检测端口占用并给出可用端口；桌面版修复 Electron 以 Node 模式启动的问题。

规则配置与引擎已更新，引擎指纹随之变化；此前保存的回放仍可观看，逐帧重算需要其原始引擎与配置。第三方许可证与随项目分发曲目的授权说明见 THIRD_PARTY_NOTICES。
