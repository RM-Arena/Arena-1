# Arena-1 v0.7.0-beta.1

本版本仍为 **Beta**。

- 新增 `headless` 无界面对局入口，支持导入战场配置并保存 JSON 回放；批量评测支持多种子与红蓝换边。
- 开赛前可勾选保存完整 MP4，自动录制阵容介绍、对局、赛后数据与 MVP，在比赛记录中播放或下载；转码失败保留原始录像并支持重试。
- 新增按赛季保存的战场设置页，提供最多 25 项可调参数、一键恢复当前默认值和 CLI 参数导出。自定义参数保存在回放中，相关对局不计 Elo。
- 新增跨阵容策略搜索、最多三份策略并排比较和对战配对，自动载入共同阵容；继续要求双方同赛季、同注册阵容。
- 两个策略仓库中的相关策略统一使用 `claude_opus55_xhigh_*` 标识，2026 与 2027 的作者署名均为 **Claude Opus 5.5 xhigh**。策略生成器、训练模板、策略更新源与文档同步更新。
- 兼容读取此前保存的策略标识、卡组与回放展示信息。配置和观测中的规则摘要字段改为 `rulebook` / `rulebook_rules`；依赖旧字段的自定义工具需相应更新。新策略库要求客户端至少为 v0.7.0-beta.1。

完整 MP4 由观战页面录制，保存完成前需保持页面打开。终端计算模式输出可复现 JSON 回放。

引擎指纹已变化；此前保存的回放仍可观看，逐帧重算需要其原始引擎与配置。第三方许可证保持原文。
