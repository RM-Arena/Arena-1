**Getting started**

1. Run `python3 -B arena.py status` to confirm the development clock has started and note how much time is left.
2. Read this guide. On a first pass, "Task and Constraints", "Match Overview", {{#robot}}"Your Robot", "Your Team", {{/robot}}and "Information and Control" are enough; look up the other chapters as you need them.
3. Read {{source_files}}. It is a runnable template that already buys ammo, revives, assembles tech cores, flies air support and attacks structures{{#robot}}, and it works for any slot{{/robot}}.
4. Run one short practice game to check your setup: `python3 -B arena.py test --duration 30`.
5. **Submit early**: `python3 -B arena.py submit`. Whatever happens later, you then have a valid entry.
6. Then iterate: change → practice → read results and replays → submit.
