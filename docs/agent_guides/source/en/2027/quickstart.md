**Getting started**

1. Run `python3 -B arena.py status` to confirm the development clock has started and note the time left.
2. Read this guide. On a first pass, "Task and Constraints", "Match Overview", "Control Positions and Control Degree", "Robot Mechanics" and "Interface Reference" are enough; look up the rest when needed.
3. Read {{source_files}}. It is a runnable template that already buys ammunition, runs the heavy robot's assemblies and launcher fitting, switches sentry postures, rams the enemy outpost and base with aerial robots, and advances and captures with the infantry.
4. Run a short practice game to check the setup: `python3 -B arena.py test --duration 30`.
5. **Submit early**: `python3 -B arena.py submit`, so you always hold a valid entry.
6. Then iterate: edit → practice → read results and replays → submit.
