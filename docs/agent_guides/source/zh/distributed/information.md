## 信息与控制

开发时你可以编辑六份策略，比赛时每个进程仅挂载对应的一份源码（在容器中命名为 `strategy.py`）。不允许在六份源码之间 import，不共享模块变量或 `state`。每个 `act` 的 `controlled_ids` 只有自身编号，返回其他编号会停用该进程；一个进程出错不会停用其余五个。

视觉观察仅来自该进程控制的机器人。`enemies` 不自动合并队友视野；己方六台机器人的完整公开状态、己方经济与裁判信息仍可读取。英雄部署后、空中支援关闭时以及阵亡期间没有自身视野。队友可以通过 `messages` 主动发送情报与意图；它们是上一轮的策略消息，不是引擎保证准确的当前观测。

地面相机的水平视场为{{ground_fov_horizontal}}°、垂直为{{ground_fov_vertical}}°，随实际炮口方向转动，并继续受距离和遮挡限制。无人机保持原覆盖。己方全部位置与裁判信息始终可读。
