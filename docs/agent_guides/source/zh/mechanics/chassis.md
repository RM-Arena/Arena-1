## 底盘物理与精细控制

所有地面机器人都是 120 Hz 的刚体仿真：有质量、惯性、悬架、轮胎抓地和碰撞。`move` 只是速度意图，真正的运动由电机力、功率和摩擦决定。下面这些物理细节会直接影响战术。

### 断电与惯性

裁判系统在以下情况切断底盘电源：机器人被击毁、超功率断电（见「功率与能量」）、电池耗尽。此时 `powered == False`：

- 电机失去驱动，也失去制动。机器人**按惯性继续滑行**，只受齿轮箱回拖、滚动阻力和碰撞阻挡。麦轮底盘的滑行减速度约 2.2 m/s²（3 m/s 时约滑 2 m）；坡度超过约 12° 时（例如 17° 飞坡）没电的麦轮车会顺坡下滑。
- 被击毁的机器人留在原地成为**残骸**：仍是实体，会挡路、挡子弹、挡视线，也可以被推动。复活在原地进行，复活后恢复供电；翻倒的机器人复活后仍然是翻倒的。
- 有电且没有 `move` 时，电机主动刹车，保持位置与朝向（受轮胎摩擦限制）。发送 `brake=False` 可以让有电的底盘自由滑行。

### 翻倒与扶正

- `upright` 是车身竖直轴与世界竖直方向夹角的余弦（1 为正立）；低于 0.5 时 `tipped == True`。翻倒的车轮离地，无法自行行驶。
- 常见原因：高速冲出坡道侧边、跌落台阶、飞坡落地不稳、被撞。
- 工程可以用机械臂把翻倒的队友扶正（工程的 `rescue` 动作）。{{#c_s3}}双轮足型号从正面或背面倒地时能用腿自己站起来，但侧翻时同样需要工程扶正。{{/c_s3}}

### 精细控制字段

| 字段 | 作用 |
| --- | --- |
| `move` | 世界坐标速度意图，[−1, 1]，乘以参考速度 |
| `heading` | 底盘目标朝向；省略时麦轮车转向运动方向 |
| `yaw_rate` | 底盘目标角速度（rad/s，最大 ±12），优先于 `heading`。麦轮车可以一边平移一边自旋（“小陀螺”），让敌人难以持续命中同一块装甲 |
| `power` | 本次底盘功率预算（0–200 W）。高于功率上限的部分由超级电容补足，电容耗尽后缓冲能量开始下降 |
| `brake` | 默认 `True`；`False` 时无 `move` 也不主动刹车 |

自旋会消耗功率：转矩乘角速度计入底盘功率，持续自旋时注意功率上限。

### 起伏路段

- 公路护边以南（红方 x 5.25–7.65，蓝方镜像）铺满 10 道高 70 mm、间距 240 mm 的圆滑凸起。普通轮式机器人从缺口西侧的 10° 坡上公路后，必须越过它才能到公路东段、飞坡和高地端坡。
- 轮式底盘离地 100 mm，悬架较软，车轮随凸起起伏而车身基本保持水平：直线全速驶过即可，约 3–5 s。低速爬行（尤其较重的双臂工程）可能停在两道凸起之间，后退一点再加速冲过。
- 不发送 `power` 时，有超级电容的英雄和步兵在凸起上会自动用电容补足功率；发送 `power` 则以你的预算为准。
- 双轮足的两个车轮同时爬升，需要全速驶入，并走路段中部；贴着两侧护边容易被晃上去卡住。

### 双轮足型号

双轮足型号是主动平衡机器人：机体由左右两条五连杆腿支撑，腿端是轮毂电机车轮，机体靠主动平衡保持直立。它和麦轮车有本质不同：

- **不能横移**。`move` 的方向会让底盘先转到该方向（前进或倒车中较近的那个），再沿车身前后方向行驶。若同时给出 `heading`，则只执行 `move` 在车身前后方向上的分量——想沿直线车道行驶时这样最稳。
- `leg_height`：腿长（髋到轮轴）的限位、默认值与速率取所选型号的 `leg_min_m`、`leg_max_m`、`leg_nominal_m`、`leg_speed_mps`。腿长变化会整体抬高或降低机体和装甲。
- `jump`：跳跃力度 0–1（`True` 等于 1）。只在车轮着地时触发，冷却与推力分别取 `jump_cooldown_s` 和 `jump_thrust_gain`。双腿以 (1 + 推力系数×力度)×重力 的推力伸展，离地后自动收腿。以默认 W3 为例，全力起跳机体约升高 0.4 m，收腿后轮底离地约 0.5 m，足以跳上 0.4 m 的中央高地垂直边缘（在距台阶约 0.5 m 处以约 2 m/s 起跳）。
- `lean`：机体俯仰目标（rad，±0.35，正值为前倾），可用于加速或调整飞坡落地姿态。空中只能用轮子的反作用力做很小的姿态修正。
- 腿部关节电机不计入裁判底盘功率，但会消耗电池（约 18 W）。
- 断电时（包括被击毁）腿部失去力矩而塌陷，平衡停止，机体沿惯性向前或向后倒下滑行。复活后若是正面或背面着地，会自己站起来。

**飞坡**（`sdk.fly_slope_lane(arena, team)` 给出几何）：己方飞坡在己方公路的尽头，是朝中线方向升高的 17° 坡道。公路（0.2 m）直接接上坡道低端（唇口，0.203 m，前面没有台阶），坡顶高 0.553 m；坡顶前是 0.65 m 宽、低到地面的沟隙，对面是对方半场梯形高地尖端 0.2 m 高的着陆台。以红方为例：唇口 x = 12.55，坡顶 x = 13.695，着陆台边缘 x = 14.345，车道中心 y = 14.4；两张飞坡增益卡分别在坡前的公路上（x ≈ 10.6）和着陆台之后（x ≈ 16.27）。坡道两侧各有 141 mm 宽、高出坡面 151 mm 的护栏，中间车道宽 860 mm。坡顶之后直到第二张卡是公路禁区：只有从坡底完整冲到坡顶再飞入才允许进入，可以停留或驶出；从地面或对方梯形高地开进去会被挡住。

- 正向：在公路上加速（`power=200`）后保持直线冲坡，不需要起跳；离开坡顶时速度约 2.4 m/s 以上即可越过沟隙。
- 反向：从着陆台以约 2.5 m/s 向坡道行驶，在沟隙边缘前 0.3–0.4 m（红方约 x = 14.65–14.75）全力起跳，可直接落上坡顶，再顺坡驶回公路。
- 飞坡对时机很敏感，起跳点或速度偏差会导致落进沟隙或翻倒。请在练习中针对自己的控制方式标定。
- 唇口与公路齐平，麦轮等普通底盘也能从公路驶上坡道；但低速爬不上坡顶，全速飞越后又容易落地翻倒，需要自己标定速度。
