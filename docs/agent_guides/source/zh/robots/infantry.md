### 步兵的能力

三台步兵（3、4、7 号）遵守完全相同的规则，区别只在硬件和默认性能。步兵是 17mm 火力的主体，下面两件事只有步兵能做：

- **启动能量机关**：`rune_start=True`，然后用 17mm 依次击中亮起的目标（见「能量机关」）。
- **占领堡垒**：己方前哨站首次被毁后，占领己方堡垒可获得 50% 防御、冷却加成和储备弹量；180 s 后、对方前哨站处于被毁状态时，可以占领对方堡垒，使对方基地护甲展开（见「堡垒」）。

和英雄一样，你还可以兑换弹量、远程回血、占领中央高地，并能在己方前哨站区域连续停留 10 s 重建前哨站。17mm 的兑换额度（整局 1000 发）由三台步兵共用。

### 性能选择

只能在 `tick == 0` 时改选，之后锁定：

```python
action(profile={"chassis": "hp", "weapon": "burst"})   # 也可以只给其中一项
```

| 选项 | 1 级数值 | 特点 |
| --- | --- | --- |
| 底盘 `"hp"` 血量优先 | 200 血，45 W | 更耐打，功率低 |
| 底盘 `"power"` 功率优先 | 150 血，60 W | 加速与持续机动更好 |
| 发射机构 `"cooling"` 冷却优先 | 热量上限 40，冷却 12/s | 适合持续射击（约每秒 1.2 发） |
| 发射机构 `"burst"` 爆发优先 | 热量上限 170，冷却 5/s | 一次可连发约 17 发，之后恢复很慢 |
