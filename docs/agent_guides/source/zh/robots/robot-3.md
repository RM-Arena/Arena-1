## 你的机器人：3 号步兵（双轮足）

### 定位

你是双轮足平衡步兵：机体由两条五连杆腿支撑，腿端是轮毂电机车轮，靠主动平衡直立。你能调节腿长、跳上 0.4 m 的台阶、飞坡甚至反向飞坡，是全队越障能力最强的机器人；代价是不能横移，并且被击毁断电时会倒地。默认血量 150。

{{own_hardware}}

- 发射机构：17mm，出膛 25 m/s，最短发射间隔 0.05 s，每发热量 10。
- 预选性能：**功率优先底盘 + 冷却优先发射机构**，1 级为 150 血、60 W、热量上限 40、冷却 12/s。
- 腿长 0.12–0.34 m（默认 0.20 m）；装甲中心高随腿长变化：0.28 m + (腿长 − 0.20 m)。完整参数见 `sdk.DESIGNS["3"]`。

### 打法要点

- 你是“差速”底盘：转向需要时间，急转时先减速。沿车道直行时同时给出 `heading`，横向偏差用小角度修正，比用 `move` 横向分量更稳。
- 跳跃能直接上高地、越过沟隙，开辟别人走不通的路线；起跳点、速度和力度都要在练习中标定（见「底盘物理与精细控制」）。
- 降低腿长能降低装甲高度、在跳跃前蓄力；升高腿长能越过低矮遮挡观察或射击。
- 150 血不适合长时间正面对射。利用增益点和地形跨越的防御增益，打完就撤。
- 被击毁后会倒地；若侧翻，需要工程用 `rescue` 扶正，否则复活后也无法行驶。
