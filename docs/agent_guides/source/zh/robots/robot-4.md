## 你的机器人：4 号步兵（爆发型）

### 定位

你的默认发射机构是爆发优先：1 级热量上限 170，能连续打出约 17 发，但冷却只有 5/s，打空热量后需要很久才能恢复。车身重量中等，参考速度 4.2 m/s。

{{own_hardware}}

- 发射机构：17mm，出膛 25 m/s，最短发射间隔 0.05 s，每发热量 10。
- 预选性能：**功率优先底盘 + 爆发优先发射机构**，1 级为 150 血、60 W、热量上限 170、冷却 5/s。

{{> robots/infantry}}

### 打法要点

- 把热量留给关键窗口：敌人进入近距离、对方前哨站或基地装甲暴露、能量机关激活期间。不要在无效目标上耗光热量。
- 爆发后冷却很慢（1 级每秒只恢复 0.5 发）。隧道跨越（冷却 ×2，120 s）、大能量机关的冷却倍率和己方堡垒的冷却加成都能显著改善这一点。
- 热量超过上限要冷却到 0 才能再射击，达到“上限 + 100”会永久锁定；大热量池更要注意不要冲过上限。
- 如果你更想要持续火力，可以在 `tick == 0` 时改选冷却优先。
