## 性能选择、等级与经验

### 性能选择

英雄和步兵各有一套预选性能，只能在**第一次决策（`tick == 0`）**时修改，之后锁定。

| 兵种 | 可选项 | 预选 |
| --- | --- | --- |
| 英雄 | `"ranged"` 远程型 / `"melee"` 近战型 | 所选型号的 `hero_profile` |
| 步兵底盘 | `"hp"` 血量优先 / `"power"` 功率优先 | 所选型号的 `chassis_profile` |
| 步兵发射机构 | `"cooling"` 冷却优先 / `"burst"` 爆发优先 | 所选型号的 `weapon_profile` |

```python
action(profile="melee")                               # 英雄
action(profile={"chassis": "hp", "weapon": "burst"})  # 步兵，也可以只给其中一项
```

- 工程和空中机器人没有性能选择。
- 只有具有部署机构的远程型英雄能部署。近战型英雄血量、功率和热量上限更高，但冷却更慢。
- 各等级的具体数值见{{#team}}「附录：等级性能表」{{/team}}{{#robot}}「你的机器人」{{/robot}}，完整数据在 `sdk.RULES["profiles"]`。数值不一定等差，例如步兵冷却优先 9 级的热量上限是 114。

### 等级与经验

等级从 1 开始，累计经验达到下表数值即升级：

{{xp_table}}

- 等级上限初始为 **5**。工程首次完成 2 级装配后提升到 **7**，首次完成 3 级装配后提升到 **10**。达到当前上限后不再积累经验。
- 升级会提高血量上限、底盘功率、热量上限和冷却（具体取决于兵种和性能），新增的血量上限立即加到当前血量上。空中机器人升级只提高热量上限和冷却。
- 工程不获得经验，始终为 1 级。
