### 如何配合

- **读队友状态**：`observation["robots"]` 包含每个队友的完整公开状态，例如位置、血量、弹量、热量、等级、是否阵亡、`carried_units`（工程携带的能量单元数）、`deployed`（英雄是否部署）、`support_active`（空中支援是否开启）。
- **读经济事件**：`referee["events"]` 中的己方事件带有 `robot` 字段，可以看出是谁兑换了弹量、谁升了级。
- **金币是公共的**：队友也会兑换弹量、远程回血和立即复活，空中支援超出免费时间后也按秒扣钱。不要假设余额都归你；花钱前考虑队友可能的需要。
- **结算顺序**：同一时刻多台机器人发起消费时，按编号 1→2→3→4→6→7 依次结算。余额不足的请求直接失败，不扣钱，也不报错。
- **视野不共享**：队友看到的敌人不会自动出现在你的 `enemies` 中；队友可以用消息发送其观察到的位置与意图。但裁判快照里的敌方血量变化、击毁播报和队友的掉血，都能提示哪里在交战。
- **不要把成败押在某个队友身上**：队友的程序可能表现不稳定，甚至出错停用。你的策略应能独立运转。
