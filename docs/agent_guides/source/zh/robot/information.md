## 信息与控制

### 你控制什么

你的程序只控制己方 {{slot}} 号。`observation["controlled_ids"]` 恒为 `["{{slot}}"]`，返回的 `actions` 只能包含键 `"{{slot}}"`；出现其他编号会导致程序被停用。

### 你能看到什么

信息分两类。

**视觉观察（只来自你自己的机器人）**

- `observation["enemies"]` 只包含**你的机器人当前能看到**的敌方机器人（包括残骸），带外观可见的全部状态：位置、速度、姿态、云台指向、血量、是否翻倒、机械臂与腿的状态等（见「接口参考」）。队友看到的敌人不会出现在这里。
- 你的视距为 {{vision}} m。你从相机位置向目标车体中心、云台顶部和四块装甲板分别看去，任一视线不被墙体、地形、结构或其他机器人（包括机械臂、残骸）挡住就算看到。阵亡期间没有视野。`observation["vision"]` 还列出你看到的己方队友。
{{#hero}}
- 部署后你失去第一视角，`enemies` 始终为空，直到取消部署。
{{/hero}}
{{#aerial}}
- 只有空中支援开启时你才有视野；支援关闭时 `enemies` 为空。
{{/aerial}}
- 敌方弹丸只在你的视野内可见；己方（包括队友）的弹丸始终可见。
- 只有当你与能量机关中心的距离不超过视距时，才提供能量机关目标的位置。

**公开信息（不受视野限制）**

- 己方六台机器人的完整状态，包括队友的位置、血量、弹量、热量和等级；
- 双方全部机器人的编号、兵种、血量、血量上限和存活状态（裁判快照 `referee`）；
- 双方基地与前哨站的血量、护甲、护盾、是否曾被击毁和装甲旋转状态；
- 双方攻击伤害累计、双方科技核心装配状态、各增益点的占领状态；
- 己方经济；地图、规则参数和机器人设计。

**不公开**：对方的金币、弹量、热量和经验；看不到的敌方机器人的一切位置信息；任何其他参赛者（包括你的队友）的代码、私有 `state` 和日志。

知道敌人的血量不等于知道它在哪里。`referee` 中的机器人列表不含坐标，不要用它构造瞄准目标；瞄准可使用 `enemies`，或队友主动发来的位置情报（注意发送时间和可信度）。

地面相机的水平视场为{{ground_fov_horizontal}}°、垂直为{{ground_fov_vertical}}°，随实际炮口方向转动，并继续受距离和遮挡限制。无人机保持原覆盖。己方全部位置与裁判信息始终可读。
