# 机器人策略对战 · 全队赛参赛手册（RMUC 2027）

本手册是 **RMUC 2027 规则**下全队赛的完整规则与接口说明。你要编写一个 Python 程序，**同时控制己方全部五台机器人**，与另一支同样由程序控制的队伍对战。比赛过程中不会调用语言模型，所有决策都由你的代码实时做出。

## 速览

| 项目 | 内容 |
| --- | --- |
| 交付物 | `strategy.py`，其中定义 `act(observation, state)` |
| 你控制 | 己方 1 号重型、3/4 号步兵、6 号空中机器人系统、7 号哨兵，共五台（没有 2、5 号） |
| 决策节奏 | 每 0.1 s 调用一次 `act`，每次须在 200 ms 内返回 |
| 单局时长 | 420 s；任一方基地被击毁时提前结束 |
| 开发时间 | 默认 90 分钟，由组织者启动计时；阅读、编码、测试、提交全部计入 |
| 参赛版本 | 截止前最后一次成功提交的版本 |
