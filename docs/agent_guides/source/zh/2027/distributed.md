# 机器人策略对战 · 模式 C 参赛手册（RMUC 2027）

本手册是 **RMUC 2027 规则**下模式 C 的完整规则与接口说明。开发时由一个 agent 编写五份策略；比赛时五份策略分别在独立进程中决策，**各自只控制对应的一台机器人，维护独立 state**，通过队内消息配合。比赛过程中不会调用语言模型，所有决策都由你的代码实时做出。

## 速览

| 项目 | 内容 |
| --- | --- |
| 交付物 | {{source_files}}，每份定义 `act(observation, state)` |
| 你控制 | 每份策略控制对应编号；合计 1、3、4、6、7 号 |
| 决策节奏 | 每个进程每 0.1 s 调用一次 `act`，各自须在 200 ms 内返回 |
| 单局时长 | 420 s；任一方基地被击毁时提前结束 |
| 开发时间 | 默认 90 分钟，由组织者启动计时；阅读、编码、测试、提交全部计入 |
| 参赛版本 | 截止前最后一次成功提交的版本 |
