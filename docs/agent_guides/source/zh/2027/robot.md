# 机器人策略对战 · 单机器人赛参赛手册（RMUC 2027 · {{robot_title}}）

本手册是 **RMUC 2027 规则**下单机器人赛的完整规则与接口说明。你要编写一个 Python 程序，**只控制己方 {{slot}} 号{{role_name}}**。己方另外四台机器人分别由其他参赛者独立编写的程序控制：你们共享金币与胜负，可以通过队内消息通信。比赛过程中不会调用语言模型，所有决策都由代码实时做出。

## 速览

| 项目 | 内容 |
| --- | --- |
| 交付物 | `strategy.py`，其中定义 `act(observation, state)` |
| 你控制 | 己方 {{slot}} 号{{role_name}}（`controlled_ids == ["{{slot}}"]`） |
| 队友 | 己方其余四台，由其他参赛者的程序控制，支持队内通信 |
| 决策节奏 | 每 0.1 s 调用一次 `act`，每次须在 200 ms 内返回 |
| 单局时长 | 420 s；任一方基地被击毁时提前结束 |
| 开发时间 | 默认 90 分钟，由组织者启动计时；阅读、编码、测试、提交全部计入 |
| 参赛版本 | 截止前最后一次成功提交的版本 |
