## 本版本不冒充 CAD 或真实裁判硬件

赛事数值、货币、经验、期限与胜负条件来自手册；以下属于软件表达方式，均在 `simulation_assumptions` 标明：

1. 机器人速度、加速度、底盘功率到速度的映射、炮塔转速、视野半径、扳机采样上限、碰撞包络与装甲尺寸代理。本次新增制作规范另给出质量、尺寸、电压、装甲安装等边界，已在硬件设计中执行。运动驱动、摩擦、悬架等仍为设计参数。
2. 未完整标注的地图模块轮廓、卡片区域和禁区使用图示近似；地图不是官方 CAD。可明确确认的 28×15m、围挡及已发布坡度独立录入。
3. 工程末端对准通过高层动作表达，插入/平移/旋转用统一机械速度；四级期限与两核心要求不被省略。虚拟资源派发与携带上限是模拟硬件，不是官方库存数量。
4. 无线充电实际输入功率是统一模拟值；官方只给了供电最大200W，不能把最大供电直接当成所有机器人的实际充电速率。
5. 无随机硬件离线、漏检、感应死区或人类主观意图处罚。虚拟裁判模块默认为在线；非法地区动作被运动约束阻止。
6. 飞坡/隧道等区域具有规则卡片与增益状态，但细部轮胎接触、悬架、完整道路 CAD 与机械碰撞仍是运动学代理。

## 该 PDF 自身的歧义处理

- p67 表5-3：42mm列的末行含17mm字样，部分超速区间未定义。公共策略不允许设定非法弹速，配置保留原边界，不猜测缺失处罚。
- p68：段落写 `Q1 > Q2`，图5-1写 `Q1 >= Q2`。本版以图5-1永久锁定边界执行。
- p104：堡垒示例中的150冷却与规范公式上限75不一致。执行明确公式 `min(75,floor(Δ/40))`。
- 堡垒库存补充节奏没有明示。储备在启用/容量增加时增加；容量随当前基地血量变化，基地回血后裁剪超上限余弹，离开再进不无限重置。
- 小机关与大机关阶段机会分别保存，不把未用小机关次数偷偷换为大机关次数；已获得增益按持续时间保留。

## 装甲命中与血量判定修复（2026-10-11）

本轮以真实弹丸扫掠复现并修复以下问题：

- 双轮足模型将四块装甲外移30mm，判定面却仍用旧安装位置，弹丸被粗略车体碰撞体提前截住；装甲表面的11mm偏移也未计入，工程机器人前装甲上部同样受影响。安装偏移与受击面偏移现由 `robot_designs` 同时供 Blender 和 Rust 使用，并约束双轮足粗略车体不覆盖外露装甲。现有GLB的受击面位置无需改变。

- 相对速度仅减去车体平移速度，漏算旋转装甲的局部运动。现使用 Rapier 的实际受击点速度计算法向相对速度，修正擦边、自旋时的有效伤害判定。

## 完整规则回归与裁判系统补齐

### 发现并修复的实现问题

1. 基地回血后，堡垒储备弹池仍保留旧容量，可能超过当前HP对应的上限。现在更新容量、裁剪超额余弹，并保持离开再进不凭空补弹。
2. 堡垒占领首次检测会多计一帧，可能提前展开护甲；现在只累计连续有效检测之间的实际经过时间，首帧不计入尚未经过的时间。
3. 堡垒暂停超过3s后若在首个超时帧重新进入，旧进度会先被续上再更新时间，绕过清零。现在先处理超时，再恢复计时。
4. 永久热量禁发标记在复活时被清除。现在自然和购买复活均保留永久锁定；热量冷却、超弹速锁定、永久锁定相互独立。
5. 四级装配抢占时，低级装配的15s缓冲被误写成暂停。手册明确允许缓冲期内确认或退出；现在保留原核心就位时间，另存`buffer_until`，期间可以继续操作，超时未完成则退出。
6. 地面机器人的己方停机坪权限在SDK导航与物理引擎不一致；现在双方停机坪均禁止地面机器人进入，空中机器人仍可使用停机坪。

### 复活辨识、42mm散布与自由赛控制（2026-10-12）
